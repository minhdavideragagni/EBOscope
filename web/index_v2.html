Epistemic Bias Ontology explorer · public prototype
Go beyond “it is biased”

See what's behind a bias claim.

Enter a named artefact, process, dataset, map, model, document, or public work. EBOscope searches the web for documented assessments and reconstructs how an epistemic-bias qualification is scoped and supported.

Not a bias detector.
No global score. No “biased / unbiased” verdict. It reconstructs what sources actually argue, then makes the reasoning explicit through EBO.

Why EBO?

The ontology is the logic behind the explanation.

Assessment ≠ label

EBO keeps the act of assessing separate from the qualification it produces.

Context stays attached

Who assessed what, for which purpose, under which criterion and using what evidence can travel with the claim.

Machine-readable reasoning

The same reconstruction can be inspected visually and exported in JSON-LD for downstream software or AI agents.

EBOscope reconstructs documented claims; it does not certify that a source is correct.
