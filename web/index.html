EBOscope
An application based on the Epistemic Bias Ontology (EBO)
Epistemic bias · contextualised

From bias claims to contextualised qualifications.

When something is described as biased, EBOscope asks who assessed what, according to which criterion, using what evidence, and for what purpose — then represents that assessment through EBO.

Not a bias detector.
EBOscope reconstructs documented assessments. It does not turn every limitation into bias, and it never treats a missing result as evidence that something is unbiased.
Retrieval currently looks for explicit bias / biased language, using several query formulations to improve recall. No user API key required.

Why EBOscope?

Bias claims become more useful when their context can travel with them.

Compare

Compare different qualifications of the same entity without collapsing them into one global “biased” label.

Query

Ask for qualifications involving representativeness, a particular indicator, method, assessor, or evidence type.

Trace

Keep a machine-readable path from source evidence and assessment activity to a resulting qualification, acknowledgement or mitigation.

Reuse

Pass a qualification to a knowledge graph, digital heritage workflow or AI agent without stripping away who assessed what and under which criterion.
